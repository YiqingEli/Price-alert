# 行情警报 → Bark

美股恐慌指标警报，触发后推送到 iPhone。跑在 GitHub Actions 上，不依赖本地电脑。

## 判据

每档四项：**波动**(VIX) / **恐慌**(CNN Fear&Greed) / **强弱**(QQQ 日线 RSI6) / **价格**(纳指QQQ 或 标普SPY 任一跌幅)

| | 波动 | 恐慌 | 强弱 | 价格 |
|---|---|---|---|---|
| **一档（加仓）** | VIX > 25 | F&G < 20 | RSI6 < 30 | 跌 > 2% |
| **二档（抄底）** | VIX > 33 | F&G < 10 | RSI6 < 22 | 跌 > 3% |

强弱项用 QQQ 的已收盘日线历史拼接今日实时价计算，Wilder 平滑，与 TradingView 的 `ta.rsi()` 一致。日线历史一个任务内只拉一次并缓存。

- 满足 **≥1 项** → 发警报
- 满足 **≥2 项** → 标题前加「加仓」/「抄底」
- 只发最高档；当天已推过高档就不再推低档
- 同一档**项数创当天新高**才推送（1→2→3 各推一次，掉回去不重复）
- 跌幅按**昨收**计算，盘中实时判断

## 推送样式

```
抄底 · 二档 3/4
─────────────────
✅✅ 波动 35.2
✅❌ 恐慌 12
✅✅ 强弱 21.0
✅✅ 纳指 612.40  -3.81%
✅✅ 标普 698.15  -3.14%

勾序＝一档｜二档，价格项取纳指/标普任一
一档 4/4 · 二档 3/4 · 03-20 10:15 ET
```

## 运行机制

- cron 每 5 分钟触发（UTC 13-21 点，周一至周五），**脚本内部再循环 4 分钟、每 60 秒查一次**，所以实际轮询间隔是 1 分钟
- 用 CNBC 的 `curmktstatus`（只取 QQQ/SPY 的，不用 .VIX——CBOE 有延长时段，状态不同步）判断是否盘中，自动处理半日市和节假日；拿不到时退回美东 9:30-16:00
- **非交易时段不做任何判定**：周末 cron 不触发（`1-5`）；节假日 cron 会触发但每轮直接跳过，不会因为拿到旧数据而误报
- 时间戳若不带时区（休市时 CNBC 只返回日期），一律按美东解释，避免受运行机器时区影响
- 四项全部取不到数据需**连续两轮**才告警，避免开盘瞬间时间戳未刷新造成误报
- **临近开盘时会等待**：任务若在开盘前 8 分钟内启动，会 sleep 到 9:30:05 再开始，保证开盘瞬间就有覆盖（对冲 GitHub cron 5-15 分钟的漂移）
- 状态在内存累积，任务结束时一次性提交 `state.json`；推送冲突会自动 rebase 重试

## 数据源与延迟（实测）

| 项目 | 主源 | 延迟 | 备源 |
|---|---|---|---|
| 波动 VIX | CNBC | ~10 秒 | CNN 分项（延迟 18 分钟，会标注「实时数据缺失」） |
| 价格 QQQ/SPY | CNBC | ~1 秒 | Nasdaq |
| 恐慌 F&G | CNN | ~5 分钟 | 无 |
| 强弱 RSI6 | Nasdaq 日线 + 实时价 | 跟随价格 | 无 |

任一项取不到、或拿到的是昨天的数据 → 显示 ⚠️ 且**不计入分母**（标题会标「部分数据缺失」）。三项全缺 → 发一条数据源失败告警，每天最多一次。

## 改配置

编辑 `config.json` 即可，不用改代码：

```json
"tiers": [
  { "name": "一档", "label": "加仓", "vix": 25, "fng": 20, "rsi": 30, "drop": 2.0 },
  { "name": "二档", "label": "抄底", "vix": 33, "fng": 10, "rsi": 22, "drop": 3.0 }
]
```

`rsi_period` RSI 周期、`loop_seconds` 循环时长、`poll_interval` 轮询间隔、`wait_open_window` 开盘等待窗口（分钟）也在里面。

## Secrets

仓库 `Settings → Secrets and variables → Actions` 需要 `BARK_KEY`。

## 手动运行 / 排查

Actions → 行情警报 → Run workflow：
- `check` 体检，测五个数据源的**可达性**（不要求数据是当天的，所以休市时跑也应显示 5/5），并发一条测试推送
- `demo` 发一条模拟警报到手机，用来确认推送格式（不写入状态，不影响真实去重）
- `force` 无视时段强制检查一次
- `normal` 按正常逻辑跑

## 阈值依据

基于 1990-2026 的 VIX/SPX、2021-2026 的 F&G、2025-2026 的 QQQ 数据回测：VIX 上穿 18-22 无统计边际（收益低于随机买入基准），边际从 25 开始出现、33 以上显著；F&G 跌破 25 同样无边际，15 以下才有效，10 以下 6 次全对且入场后平均最大浮亏仅 -1.3%。QQQ 日线 RSI(6) 低于 30 约 14.6 天/年、低于 22 约 6.0 天/年，分别与一档、二档其他项的频率匹配。
